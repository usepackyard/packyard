Install Packyard

Private Composer package registry — one binary, your server.

Run this on a fresh Linux or macOS host:

curl -sSf https://get.packyard.dev/install.sh | sh

The script downloads the right binary for your architecture, verifies the SHA-256 checksum, places it in /usr/local/bin (or ~/.local/bin for non-root installs), then hands off to packyard init — an interactive wizard that configures paths, database, port, public URL, storage, admin user, and service install.

Unattended install (CI / config management): 

curl -sSf https://get.packyard.dev/install.sh | sh -s -- \
  -- --unattended \
     --port 9090 \
     --url https://repo.example.com \
     --admin-email admin@example.com

See the README for the full env-var list and the installation guide for air-gapped installs, reverse-proxy snippets, and upgrade notes.
